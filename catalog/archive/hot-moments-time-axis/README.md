# 가로 시간축 구성 (아카이브, 2026-09-05)

파형 + 시간축을 화면 폭 전체에 깔고 순간 카드를 실제 시각 위치에 매다는 구성.
카드 사이 간격이 곧 시간 간격이라 구성이 데이터에서 나오고, 1위는 아랫줄
가운데에 가장 크게 앉는다. 줄 배정(`[false,true,true,false,true]`)은 시각
간격을 보고 손으로 정한 값이라 순간 수가 바뀌면 다시 본다.

큐레이션 홈에서는 "대시보드·랜딩 느낌"이라는 판단(조현빈, 2026-09-05)으로
뺐다. **랜딩(HP-87)에서 "반응이 몰린 순간을 찾아 그 시각부터 본다"를 한 화면에
설명하는 데 쓸 후보**로 보관한다. 소스 `HotMoments.tsx`, 캡처 `desktop-1440.png`
`mobile-390.png`.
